# Suwayomi Kindle Client

面向 Kindle 的独立 KOReader 漫画客户端。通过「工具 → Suwayomi Kindle」打开，底部有书架、探索、下载和设置四个入口。

## 连接与使用

1. 在「设置 → 连接」输入 Suwayomi Server 地址，选择无认证、Basic Auth 或账号登录，点击「保存并验证」。
2. 进入「书架」。首次打开会从服务器拉取漫画，以后优先显示本地索引。点击标题左侧菜单打开抽屉，再点「从服务器刷新」可更新成员和摘要。三列书架在封面下显示书名和作者，右上角标记「未读」「已读」或在读进度（已读章数/总章数及百分比，宽度不足时只显示百分比）。列表视图保留章节数和进度条。断网时仍能翻看已保存的书架和缓存封面。
3. 「探索」的源列表通过 SVG 按钮置顶、取消置顶、上调或下调。当前语言下排名第一的置顶源就是默认源；没有置顶源时，打开最近手动访问的可用源。优先级和访问历史按服务器与账号保存。源结果页可切换「热门」「最新」或搜索，显示方式在「设置 → 探索」中切换。
   在源列表或单个源中点「全源搜索」，可按置顶优先级和当前排序搜索服务器上的全部漫画源。结果随搜索逐步出现，暂停后可从当前源继续。一轮结束时，提供后续页的源可通过「加载更多结果」继续查询。
4. 底部 `<< < 页码/总页数 > >>` 支持首末页和前后翻页。点中间数字，在「页码」或「项码」输入数字后点「跳转」。两项都填时按当前排序和筛选下的项码定位。漫画源尚未返回末页时总数显示为 `?`，跳到未访问的位置才会按需向后查找，期间可从菜单取消。

5. 在书架、探索结果和漫画详情中可查看「连载中」「已完结」「休刊中」等状态。状态取自漫画源提供给服务器的元数据，无需加载章节目录；源未提供时显示「状态未知」。详情页还显示封面和简介，底部可加入或移除书架、查看全部章节或继续阅读。「继续阅读」按源的阅读顺序选择首个未读章节，本机已有文件时直接打开 CBZ，否则定位并标出该章。移出书架会保留已有的本地文件。
6. 目录中点章节名或右侧「阅读／下载」即可打开 CBZ 或排入本地下载队列。点最右侧的箭头，可切换本章已读状态、标记之前为已读或标记之后为未读。范围操作都排除当前章。
7. 目录左侧菜单可选择「自动下载 → 1／3／5 章」或「全部下载」，全部下载需确认。带二级选项的菜单项排在末尾。自动下载从首个未读章节向后补齐指定数量的未读章节，默认关闭。离开目录后任务继续，重新打开客户端可接续队列，失败章节可单独重试。
8. 「删除已读」清理本漫画已读的本地文件。「删除策略」默认跟随全局，也可单独选择不删除、直接删除或保留 1／3／5／10 章。保留顺序优先按本机标记已读时间，同一时间按目录倒序。两项漫画偏好只保存在当前账号的本机索引。
9. 「设置 → 同步」可立即上传本地阅读记录或从服务器拉取书架、目录及进度。默认拉取更新整份书架摘要，只为已打开、已缓存或有本地记录和任务的漫画更新目录。需要完整目录时选择「同步全部章节」。关闭 CBZ 时记住页码，停在末页关闭会标为已读。标记和页码先在本地保存，约 20 秒后合并上传。失败项保留供重试；有未上传记录时，手动拉取会先提示覆盖范围。同步日志按时间倒序分页，最多保留 60 条。

10. 「下载」顶部可在「下载队列」和「下载文件」之间切换。队列支持筛选、暂停、继续和重试；单项菜单和选择模式都可以确认删除任务及对应的本机文件。删除会停止进行中的下载，保留阅读记录和正在阅读的文件；被删除的章节不会被自动下载立即加回，仍可手动下载。漫画目录中的「删除已读」完成后会弹窗显示删除、失败、保留和失效记录数量。下载文件按漫画分组，点文件夹进入章节文件列表，点右侧菜单图标打开操作。文件夹和文件均可跨页多选删除。
11. 下载文件左侧菜单可扫描孤立下载，并清理所有已读下载。扫描会检查当前下载目录的 CBZ，也检查索引中仍可定位的旧下载位置，按文件列出未登记、漫画已移出书架、章节已移出目录等原因。孤立文件也可进入选择模式批量删除，路径或登记身份不符的文件不会被删除。
12. 阅读受管理的 CBZ 时，KOReader 顶部菜单的「目录」会打开整部漫画并定位当前章。末页再向后翻一次，会按漫画目录顺序打开紧邻下一章的第一页。下一章缺失时，启用了自动下载的漫画会下载后续读，其他漫画会先询问。下载等待期间离开文档或翻回其他页，会取消自动跳转。
13. 从漫画详情侧边菜单点「查找相似漫画」，或在推荐设置中开启进入详情时的自动搜索。推荐区固定在详情下方，简介可独立滚动。AniList 返回清单后立即展示当前页的占位卡，每页并发匹配最多四部作品。后台匹配和「去探索搜索」直接使用 AniList 的标题或别名，默认按简体中文、繁体中文、英语、日语依次尝试，并缓存服务器提供的 AniList 关联。核对到相同 AniList ID 后，占位卡换为可直接打开的漫画。用封面两侧箭头翻页时才匹配目标页。推荐清单和完成的匹配缓存 24 小时。

## 设置

| 入口 | 可选项 |
| --- | --- |
| 连接 | 地址、认证方式、账号、验证。密码默认隐藏，点击密码旁的「显示」或「隐藏」切换 |
| 下载 | 长按选择下载目录，最大并行数 1–5。已读文件可直接删除、保留最近 1／3／5／10 章或不删除，默认保留最近读完的 1 章 |
| 同步 | 手动上传本地记录、拉取服务器状态、分页查看日志 |
| 主题 | 白天、黑夜。切换即时生效，退出客户端恢复 KOReader 原先的显示模式 |
| 书架 | 列表或三列封面书架。书架侧栏可按书名或作者搜索，也可按最近打开、添加时间、书名、未读数或章节数排序。长按列表项或封面可继续阅读 |
| 探索 | 可分页多选漫画源语言（中文含简繁），或选择全部语言，独立的列表或封面布局。默认中文 |
| 探索 → 推荐 | 显示相似漫画、自动搜索（默认关）、推荐候选数（5–50）、优先搜索源数（1–5）、搜索书名语言优先级（默认简体中文 → 繁体中文 → 英语 → 日语，可置顶、上移、下移，简繁可合并或拆分）。默认取前 24 条，使用 3 个源 |
| 通用 | 右上角 × 是否需要确认退出，默认开启 |

每章保存为单独的 CBZ，路径为 `下载目录/Suwayomi/账号与服务器标识/漫画ID/章节ID.cbz`。下载目录默认是 `suwayomi-kindle.koplugin/downloads/`，自定义目录不受默认值变更影响。此前下载的章节仍按索引中的路径读取；升级或手动替换插件时，请保留插件内的 `downloads/` 和 KOReader 数据目录中的 `suwayomi_kindle/`。下载按页写到临时文件，校验页数后发布。SQLite 保存目录、文件路径和队列，阅读时直接打开本地文件。清理 CBZ 会保留 KOReader 阅读记录。

## 本地存储

每类设置在首次保存时分别写入 KOReader 的 `settings/suwayomi_kindle_<section>.lua`。已有的 `suwayomi_kindle.lua` 连接配置会自动沿用。每个服务器和账号有独立的 SQLite 漫画索引，位于数据目录的 `suwayomi_kindle/library/`。

刷新在后台每批读取 64 部，核对总数、分页结束标志和漫画 ID 唯一性后在同一事务里只更新有变化的漫画，保留本机最近打开时间。失败时保留上次完整结果。翻页按标题和 ID 从本地按页读取。封面视图只为当前页加载缩略图，缓存位于 `cache/suwayomi_posters/`，使用 256 个有界缓存槽。

## 本机测试

测试配置中的插件目录可链接至仓库：

```sh
ln -s /Users/xiyu/code/suwayomi-kindle-client \
  /Users/xiyu/code/koreader-test-profile/plugins/suwayomi-kindle.koplugin
```

在仓库中运行 `luajit tests/run.lua`。连接、SQLite 和后台任务测试使用 KOReader 自带的 LuaJIT：

```sh
cd /Users/xiyu/code/koreader-emulator/KOReader.app/Contents/koreader
./luajit -e 'require("setupkoenv"); dofile("/Users/xiyu/code/suwayomi-kindle-client/tests/connection.lua"); dofile("/Users/xiyu/code/suwayomi-kindle-client/tests/catalog.lua"); dofile("/Users/xiyu/code/suwayomi-kindle-client/tests/reading.lua"); dofile("/Users/xiyu/code/suwayomi-kindle-client/tests/tasks.lua")'
```

在同一运行目录执行 `python3 /Users/xiyu/code/suwayomi-kindle-client/tests/reader_flow.py` 可使用临时配置和 CBZ 检查原生目录与跨章阅读。

章节目录、下载和阅读同步的完整设计见[功能规格](docs/功能规格.md)。
