# Suwayomi Kindle Client 功能规格

> 状态：首版设计。本文中的功能和性能要求是开发与验收目标。

## 1. 项目范围

优先保证 Kindle 上这一条路径：连接服务器 → 打开书架 → 找到章节 → 下载 → 离线阅读 → 在阅读器内切换章节 → 联网补传已读。服务器继续负责漫画源、书架成员、章节目录和跨设备已读状态。客户端负责本地下载、阅读位置、离线目录和待上传操作。首版沿用现有 Suwayomi Server API。

新客户端与旧插件可以并存。使用独立的插件 ID、设置和缓存目录。旧客户端数据导入以及 Provider Library Bridge 接入安排在后续版本。

| 优先级 | 功能 |
| --- | --- |
| P0 首版 | 连接与测试、本地书架、漫画级章节目录、选章并下载、离线阅读与续章、已读同步、服务器状态重建 |
| P1 | 按源浏览与搜索、书架增删、每部漫画自动补齐和清理策略、完善的中英文界面 |
| P2 | 服务端扩展管理、在线按页阅读、旧插件数据导入、Bridge 对接、适配 KOReader 原生目录入口 |

## 2. 用户界面与章节操作

首页一级入口为「书架」「探索」「设置」。未实现的入口在对应版本上线后再显示。首版允许从书架直接进入「继续阅读」或「章节目录」，返回时恢复书架的位置和筛选。连接设置提供服务器地址和认证方式，测试结果区分网络不可达、认证失败和接口不兼容。

进入章节目录时优先定位上次阅读章节；没有记录就定位首个未读。目录显示已读、本地下载、下载中和失败状态。支持按话数跳转、按字幕组或发布版本筛选，支持查看未读、已下载和失败章节。章节身份使用服务器实例、漫画和章节的组合，话数仅用于显示或筛选。相同话数下多个版本可以共存。

多选支持连续范围和零散章节叠加，例如第 1–10 话加第 15 话。操作前显示确切的章节数；刷新、翻页或切换筛选后，选区按章节身份保留，已不存在的选择列入跳过结果。常用操作包括标记已读／未读、标记此前章节已读、下载所选和清理本地下载。大批操作分批执行，显示成功、跳过和失败数量。

## 3. 阅读器里的漫画级目录

每话存成独立 CBZ，由 KOReader 负责原生分页、缩放和页码恢复。进入阅读器后，插件提供「漫画目录」，展示整部漫画的目录，包括还没下载的话。目录用本地快照打开，默认高亮并定位当前话。

| 操作 | 行为 |
| --- | --- |
| 点已下载章节 | 切换到目标 CBZ，恢复该章节原有页码。 |
| 点未下载章节 | 提供「下载」或「下载后打开」。失败或取消时留在当前章节。如果下载期间用户已切到别处，完成时只提示。 |
| 下一章／上一章 | 按当前目录顺序和版本筛选找到紧邻章节。文件不可用时提示，保持当前页。 |
| 读完自动续章 | 可设为关闭、询问或自动打开已下载的紧邻章节，默认询问。需要联网下载时由用户决定。 |
| 返回目录 | 保留所选版本、目录页与当前阅读定位。 |

整部漫画的目录与 CBZ 文件相互独立。切换时无需拼接整部漫画，某一话的损坏或重下不会影响其他话。

## 4. 下载与文件清理

下载操作归入漫画目录。P0 支持单章、范围＋零散多选下载、暂停／继续、失败重试及本地删除。全局「下载任务」分「下载队列」与「下载文件」两视图：队列可按下载中、排队中、暂停、失败筛选，并支持多选批量重试；文件按漫画和章节展示，支持逐项或整页多选删除。P1 增加按漫画自动补齐接下来未读的章节、删除已读，以及保留最近读完的章节；每部漫画的设置覆盖全局默认值。

服务端能提供完整归档时直接流式接收 CBZ；归档不可用时在后台逐页拉取并打包。下载写入尝试专用临时文件，在完整校验后发布为最终文件。一次本地事务提交文件归属、路径索引和任务完成状态；若在文件发布与事务提交之间中断，恢复时根据尝试记录和文件身份确认是否可以接管，无法确认时保留文件并提示。暂停任务和断网等待应可区分；恢复联网不自动解除用户主动暂停。

显式删除本地下载必须核对路径、文件身份和占用。失败或被替换的文件逐个报告；正在阅读、正在写入和身份不明的文件跳过。删除 CBZ 时保留已读、阅读位置和 KOReader 元数据，除非用户另行选择清除阅读记录。

## 5. 离线状态、恢复与服务器权威

本地保留两类数据：最近一次确认的服务器快照，以及本地待上传操作。已读状态先在本地持久化，再进入待上传队列。同一章节多次标记时，保留最后一次操作。进程退出、休眠和重启后待办仍可恢复。

| 场景 | 处理规则 |
| --- | --- |
| 服务器超时、断网、认证或接口异常 | 保留上一次完整书架、章节、已读待办和下载；区分「等待网络」与「需重新登录」。空响应或不完整分页不代表删除。 |
| 恢复联网 | 仅向所属服务器同步能够确认身份的待办。服务端确认后才清除，并核对确认对应的仍是本地最新操作。部分失败只保留失败项。 |
| 待上传的章节，服务器仍显示未读 | 普通同步优先尝试提交本地待办；历史服务器快照不能覆盖尚未提交的本地操作。 |
| 服务器书架移除漫画 | 完整书架确认后，先更新显示，再询问「删除下载」或「保留下载」。保留的文件可在本地下载视图或文件浏览器继续阅读。删除前重新确认当前书架和文件身份。 |
| 服务器章节不存在或无法对应 | 以确认后的服务端目录为准。只有来源、章节标识和发布版本能唯一匹配时才重连文件。其他文件保留在本地，旧待办留档，暂停向服务器发送。 |
| 服务器地址变化 | 客户端重验服务端目录和记录归属；遇到同名、同话数或 ID 碰撞时保留待核对状态。 |

「同步」默认立即提交可发送的待办，并刷新服务器状态。「以服务器状态重建」针对缓存冲突，先完整取得书架，再按漫画更新章节；已确认的服务器已读状态覆盖本地冲突状态，未上传的旧选择可在恢复留档中找回。单部漫画的目录拉取失败时继续保留它之前可用的目录，其他结果可以提交。两个操作都显示成功、等待重试和无法对应的数量。

## 6. 同步频率

| 触发条件 | 默认策略 |
| --- | --- |
| 翻页 | KOReader 管理本地页码。首版不按页上传阅读进度。 |
| 读完一话、手动或批量标记 | 立即保存本地。有网时约 15–30 秒合并为一批，并设定最大等待时间，避免连续阅读一直推迟发送。 |
| 返回书架或退出本漫画 | 有待办且网络可用时提前发送，界面无需等结果。 |
| 网络恢复、休眠唤醒 | 有待办才调度。临时失败逐步增加重试间隔；认证失败暂停自动重试，修复连接后恢复。插件不为后台同步主动打开 Wi-Fi。 |
| 手动同步 | 跳过等待立即尝试。再次点击复用当前同步任务，避免同批内容重复发送。 |
| 无待办 | 无已读轮询。书架与目录刷新使用独立策略，进入页面先显示本地缓存。 |

接口支持批量修改时走批量，否则回退到有界的逐条发送。服务端未确认的操作保留，重复发送使用「设为已读／未读」，避免用切换型操作导致状态翻转。

## 7. Kindle 存储和性能约束

书库增长时，高频操作的工作量应接近当前漫画、当前页或当前任务的数据量。以下约束比选择具体数据库更重要：

- **书架按摘要读取。** 打开书架无需读取章节快照、下载归档或历史留档。
- **目录按漫画、按页准备。** 暂存目录、定位索引与章节状态按「服务器＋漫画」组织。首屏先绘制本地标题和状态，文件存在性和必要的元数据只核对当前页。屏幕外状态变化无需触发重绘；同一可见页的连续变化合并绘制。
- **按路径定位 CBZ。** 本地路径直接反查章节。文件身份、大小及修改证据匹配时，可复用已验证的结果；新文件、替换文件和显式验证走完整检查。启动时无需扫全盘生成索引。
- **热状态采用事务和索引。** 章节的已读、下载任务、文件归属和路径索引可以一起提交。按到期时间取一批上传、重试或清理任务。下载字节数、封面和普通日志不进入高频核心事务。书架摘要、可重建目录和旧同步留档分别存放。
- **后台工作让路给阅读。** 当前目录和用户指定章节优先，其次是可见封面，再到预下载与清理。限制并发、分页和后台文件读写量。设备休眠前停止无关调度，恢复时按需继续。
- **先验证运行环境，再选存储实现。** 先验证目标 Kindle 上 SQLite 的绑定、持久化和恢复表现。若采用文件存储，索引和状态更新必须有明确的原子提交与恢复规则；避免把全部漫画状态写到一个大文件。

## 8. 首版验收

| 用例 | 通过条件 |
| --- | --- |
| 离线续读 | 离线打开目录、读完、续读下一话；KOReader 重启后仍可返回原页并看到待同步已读。 |
| 恢复联网时有部分错误 | 成功项被确认，失败项保留。旧请求的确认不会清除更新的本地标记。 |
| 服务器下架或章节变更 | 完整书架后才询问删除；保留和删除两种选择都不回滚书架。失败分页不触发清理。相同话数的不同发布版本不会被错误重连。 |
| 下载中断 | 在下载、归档发布与索引提交阶段分别中断，重启后不会把半成品标成可读，也不会丢失已确认的下载。 |
| 目录选择 | 长列表中可用范围加单章多选；翻页和筛选变化后仍能看到实际选择，未下载的紧邻章节不会被跳过。 |
| 大书库 | 用 7、100、500 部漫画测试同一本书的冷启动与热打开，记录目录首屏、点 CBZ 到第一页、下载完成写入量，以及文件读取数、检查的记录数和重绘次数。不同书库规模不应增加日常打开同一部漫画时读取的无关目录和文件。 |

性能验收优先在目标 Kindle 上完成，再根据实测确定时间和内存预算。测试数据和日志只记录数量、耗时与错误类别，不记录账号、服务器地址或漫画名称。
